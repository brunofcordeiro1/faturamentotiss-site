Início Privacidade

Política de Privacidade

Vigente desde 27 de setembro de 2026.

Resumo: os dados ficam no computador da clínica, criptografados. O desenvolvedor não recebe nenhum dado. O Google Drive é usado só para guardar as cópias de segurança, criptografadas, no Drive da própria clínica, e o programa acessa apenas os arquivos que ele mesmo cria.

1. Quem somos

O Faturamento TISS é um programa para Windows usado por clínicas e prestadores de serviços de saúde para faturar atendimentos aos planos de saúde no Padrão TISS da Agência Nacional de Saúde Suplementar (ANS). Contato: brunofcordeiro1@gmail.com.

2. Quais dados o programa trata

Para faturar, a clínica registra no programa dados de beneficiários (nome e número da carteirinha), dos atendimentos e procedimentos, dos profissionais de saúde (nome, conselho, CBO e CPF), dos hospitais, dos convênios e dos usuários do programa. Dados de saúde são dados pessoais sensíveis pela Lei Geral de Proteção de Dados (LGPD, Lei nº 13.709/2018).

A clínica é a controladora desses dados e decide o que registrar. O programa é a ferramenta que ela usa para cumprir as obrigações de faturamento com as operadoras.

3. Onde os dados ficam

  • Num banco de dados no computador da clínica, criptografado (AES-256), que só abre com o login de um usuário cadastrado.
  • O programa não envia dados ao desenvolvedor nem a terceiros. Os arquivos XML gerados são salvos no computador, e a própria clínica os envia às operadoras.
  • As alterações feitas nas guias e cadastros ficam registradas num histórico de auditoria dentro do mesmo banco.

4. Uso do Google Drive (backup)

Se a clínica decidir conectar uma conta Google, o programa usa o Google Drive para guardar as cópias de segurança (backups):

  • Permissão pedida: apenas drive.file, que dá acesso somente aos arquivos que o próprio programa criou. O programa não vê nem acessa nenhum outro arquivo do seu Google Drive. Também é lido o e-mail da conta, só para mostrar na tela qual conta está conectada.
  • Para que é usada: criar a pasta "FaturamentoTiss Backups" e, dentro dela, enviar, listar, baixar (para restaurar) e apagar os backups mais antigos, conforme a quantidade configurada pela clínica.
  • Criptografia: cada backup é criptografado no computador antes de ser enviado. Nem o Google nem o desenvolvedor conseguem ler o conteúdo; para abri-lo é preciso um usuário e senha do programa ou a chave de recuperação da clínica.
  • Autorização: a autorização concedida pelo Google fica guardada, criptografada, apenas no computador da clínica. O desenvolvedor não recebe essa autorização e não tem acesso ao Google Drive de nenhum cliente.
  • Sem outros usos: os dados obtidos pelas APIs do Google não são vendidos, não são usados para publicidade, não são transferidos a terceiros e não são usados para nenhuma outra finalidade além do backup.

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google obedecem à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Como desconectar o Google Drive

Na tela de Backup do programa, use o botão Desconectar. Também é possível retirar a permissão a qualquer momento em myaccount.google.com/permissions. Os backups já enviados continuam no seu Drive até que você os apague.

6. Por quanto tempo os dados são mantidos

Os dados ficam no computador da clínica enquanto ela os mantiver. No Google Drive, o programa mantém apenas os backups mais recentes, na quantidade configurada pela clínica (30 por padrão), e apaga os mais antigos.

7. Direitos dos titulares

Pacientes e profissionais que queiram exercer os direitos previstos na LGPD (acesso, correção, eliminação, entre outros) devem procurar a clínica responsável pelo atendimento, que é a controladora dos dados.
